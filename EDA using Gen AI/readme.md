# Delinquency Prediction Analysis Using Gen AI 

An exploratory data analysis project focused on understanding customer payment behavior and identifying factors associated with account delinquency.

## 📊 Project Highlights

- Analyzed customer financial and payment data
- Identified missing values and data quality issues
- Analyzed late and missed payment trends
- Investigated potential delinquency risk factors
- Evaluated relationships between customer attributes and delinquency

## 📁 Project Contents

- `Delinquency_prediction_dataset.xlsx` – Project dataset
- `EDA_SummaryReport_Delinquency_Analysis.docx` – EDA report
- `Glossary.docx` – Key analytics and AI terms

## 🎯 Objective

To understand customer delinquency patterns and provide insights that can support future predictive modeling and credit-risk analysis.
